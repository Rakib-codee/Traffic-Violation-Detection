# Paper — IEEE-style project paper

`main.tex` (IEEEtran, two-column) + `references.bib` + `figures/` (generated
from real runs). Every number in the paper traces to a committed doc
(`docs/RESULTS.md`, `docs/EVENT_ROBUSTNESS.md`, `docs/ROBUSTNESS.md`) or to
`results/` run outputs (gitignored).

## Compile

### Option 1 — Overleaf (nothing to install)

1. Zip the `paper/` directory (or upload its three entries).
2. New project → Upload → select the zip.
3. Overleaf compiles `main.tex` automatically (pdflatex + bibtex, IEEEtran
   is preinstalled).
4. Export PDF.

### Option 2 — local (needs a TeX distribution)

```bash
pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
```

Regenerate figures from a fresh dropout study run:

```bash
python scripts/eval_dropout.py        # writes results/dropout/metrics.json
python scripts/make_paper_figures.py  # writes paper/figures/dropout_recall.{pdf,png}
```

## Regenerating numbers

The ablation table rows come from `docs/EVENT_ROBUSTNESS.md` (committed,
regenerated by `scripts/eval_dropout.py`). If you rerun the study, update the
paper's Table rows from the regenerated doc.
